# 🎯 Goal Slider – Study Progress Tracker (Streamlit)

A simple Streamlit dashboard to track study hours, calculate required daily pace, and visualize **Actual vs Ideal** cumulative progress.

## 🚀 Live Demo
https://goal-slider-tracker-hw5lfpvhnw7qb5p3zzpnul.streamlit.app/

## ✨ Features
- Goal settings: target hours, start date, exam date
- Daily study hour logging
- Metrics: Completed, Progress %, Required hours/day
- 📊 Progress Graph: **Actual (cumulative) vs Ideal (cumulative)**
- Persistent settings/tasks (saved locally)

## 🧰 Tech Stack
- Python
- Streamlit
- Pandas
- Matplotlib

## ▶️ Run Locally
pip install -r requirements.txt
streamlit run app.py
